# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.5.2] - 2026-11-06

### Исправлено

- Total Commander больше не падает при F3, если файлы плагина помечены
  `Zone.Identifier` (Mark of the Web) — так получается при распаковке
  скачанного архива релиза. Windows блокировал `Assembly.LoadFrom` таких
  файлов (`FileLoadException`, 0x80131515), из-за чего не загружался
  `MarkdownLister.Core`, статический конструктор плагина падал и исключение
  уходило в Total Commander (крах 0xe0434352). Загрузка зависимостей теперь
  устойчива к метке зоны, а `install.ps1` снимает её при копировании файлов.

## [0.5.1] - 2026-11-06

### Исправлено

- Файлы `.mdx` снова рендерятся как Markdown (раньше показывались обычным
  текстом), а detect-строки установщика и `pluginst.inf` пополнились
  расширениями `MKDN` и `MDTEXT` — набор расширений везде совпадает с плагином.
- `install.ps1` регистрирует плагин и в секции `[ListerPlugins64]` — 64-битный
  Total Commander находит `MarkdownLister.wlx64` после установки скриптом
  (раньше запись добавлялась только в `[ListerPlugins]`). Заодно исправлен путь
  к папке сборки `dist\` при запуске установщика из репозитория.
- Инициализация WebView2 устойчивее: кратковременные ошибки («запрошенный
  ресурс занят» и подобные) повторяются до трёх раз; если WebView2 Runtime не
  установлен, выводится понятное сообщение со ссылкой на скачивание.
- Плагин корректно читает параметры Total Commander (путь к INI и версию
  интерфейса) в `ListSetDefaultParams` — раньше из-за неверной раскладки
  структуры в лог попадали пустые значения.

## [0.5.0] - 2026-11-06

### Добавлено

- Оповещение о выходе новой версии: автоматическая проверка GitHub Releases
  не чаще раза в сутки (отключается `CheckUpdates=Off` в INI) и пункт меню
  «Проверить обновления…». О найденной версии — метка в контекстном меню
  («Доступна версия X.Y.Z») и в статус-строке; клик открывает страницу релиза.
  Единственный сетевой запрос плагина — только чтение публичного релиза,
  никаких данных о пользователе не отправляется.

## [0.4.2] - 2026-11-06

### Исправлено

- Картинки по путям, которые раньше не отображались, теперь загружаются:
  относительные с выходом выше папки документа (`../img.png`), с уже
  закодированными символами (`img/pre%20enc.png` — устранено двойное
  кодирование) и абсолютные пути Windows (`C:\...`, `\\server\share\...`).
  Абсолютный путь показывается, если файл лежит на том же диске/шаре, что и
  документ.

## [0.4.1] - 2026-11-05

### Исправлено

- Поиск по документу находит совпадения внутри блоков кода — в том числе
  фразы, разрезанные токенами подсветки, и текст через инлайн-разметку
  (например, «the `API`»). Раньше такие совпадения терялись. Служебный текст —
  кнопки «Копировать» и скрытая MathML-копия формул KaTeX — больше не
  считается содержимым документа.

## [0.4.0] - 2026-11-05

### Добавлено

- Поддержка больших файлов (проверено на файле 100 МБ): чтение, парсинг и
  рендеринг выполняются вне UI-потока, документ постепенно рендерится чанками
  (~1 МБ) с индикатором прогресса и показывается по мере готовности.
  От порога `LargeFileWarningMb` (5 МБ) включается «режим большого файла»:
  баннер-предупреждение, отключение тяжёлых украшений (подсветка кода, Mermaid,
  KaTeX, номера строк), исходник для split view запрашивается по требованию и
  стримится чанками. Жёсткий предел размера: 1 ГБ (x64) / 200 МБ (x86) —
  с понятным сообщением об ошибке.

### Исправлено

- Патологический контент больше не роняет просмотр: если Markdig отказывается
  рендерить фрагмент (лимит глубины вложенности — например, тысячи конструкций
  «[текст][метка]» в одном абзаце), фрагмент показывается экранированным
  текстом с сохранением переносов строк.
- Извлечение заголовков и статистика документа больше не создают копии текста
  по 200 МБ (`Replace` + `Split`, `Regex.Matches`) — на больших файлах это
  экономит сотни мегабайт памяти.

## [0.3.0] - 2026-11-04

### Добавлено

- Английский язык интерфейса с переключением в контекстном меню
  («Язык / Language»: Авто / Русский / English) — меню, диалоги, статус-строка,
  поиск и сообщения об ошибках. Настройка сохраняется в `MarkdownLister.ini`;
  режим «Авто» следует языку ОС.
- Escape закрывает окно просмотра (Lister) — как и в самом Total Commander.
  В Quick View (Ctrl+Q) Escape ничего не закрывает, чтобы не уронить окно TC.

## [0.2.1] - 2026-11-04

### Исправлено

- Контекстное меню больше не «залипает»: теперь закрывается кликом в документе,
  клавишей Escape и прокруткой — раньше его можно было убрать только выбором
  пункта меню (клики внутри WebView2 не гасили WinForms-меню).

### Документация

- Английская версия README (`README.en.md`) — та же структура, переключатель
  языка в обеих версиях.

## [0.2.0] - 2026-11-03

### Добавлено

- Контекстное меню плагина: правый клик по документу или Shift+F10 — темы,
  зум, split view, оглавление, печать, «Поддержать проект», «О плагине».
- Диалог «Поддержать проект» и секция доната в README (YooMoney, WebMoney, IBAN).
- Кнопка **Sponsor** на GitHub (`.github/FUNDING.yml`).
- Ленивая загрузка Mermaid и KaTeX: тяжёлые библиотеки подключаются только
  если в документе есть диаграммы или формулы — обычные файлы открываются быстрее.
- `CHANGELOG.md` — история изменений.
- Автосборка на GitHub Actions (`.github/workflows/build.yml`): сборка x86/x64
  и релизного архива при пуше и PR; по тегу `v*` — публикация GitHub Release.

### Исправлено

- Локальные изображения документа: относительные пути (`docs/images/…`) теперь
  отображаются в Lister — папка документа раздаётся плагином отдельным хостом.
- Оглавление: корректно собираются заголовки уровней 2–6.
- Рендеринг диаграмм Mermaid.

### Документация

- README: hero-блок, бейджи версии и лицензии, скриншоты, содержание.

## [0.1.4] - 2026-10-30

Первый релиз. WLX-плагин Total Commander: просмотр Markdown-файлов в стиле
GitHub по **F3** и в Quick View (Ctrl+Q).

### Добавлено

- Рендеринг Markdig (GFM: таблицы, сноски, списки задач, YAML front matter) в WebView2.
- Split view «исходник | результат» с синхронизацией прокрутки (Ctrl+M).
- Диаграммы Mermaid, формулы KaTeX, подсветка кода (highlight.js).
- Оглавление с переходами по якорям, поиск (Ctrl+F), навигация.
- Темы: System / Light / Dark + JSON-пресеты в `themes\`.
- Зум (Ctrl+колесо), ширина чтения, печать (Ctrl+P).
- Настройки в `MarkdownLister.WLX.ini` рядом с плагином; без телеметрии
  и сетевых запросов.
